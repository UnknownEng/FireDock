# Arm FEA (3D finite elements)

Generated by `analysis/fea.py`. Mesh: 37,482 quadratic tetrahedra, 185,541 unknowns (gmsh + scikit-fem).
Material: printed PA6-CF (in-plane, 6 walls + 50 % gyroid), E = 4.5 GPa, nu = 0.35, allowable 35 MPa.
Boundary: arm clamped between the bottom plate and the clamp plate up to 53.25 mm from the centre. Peak
stresses are read outside the 3 mm band next to that clamp edge, because a perfectly rigid clamp makes
an artificial spike there.

## Natural frequencies (arm + 71.7 g motor and prop)
* Mode 1: **109 Hz**, out-of-plane bending (thrust direction)
* Mode 2: **121 Hz**, in-plane bending (yaw direction)
* Mode 3: **534 Hz**, torsion (arm twisting)
* Mode 4: **889 Hz**, out-of-plane bending (thrust direction)
* Mode 5: **1013 Hz**, in-plane bending (yaw direction)
* Mode 6: **1484 Hz**, axial

Beam theory gave 116 Hz for the first bending mode. Props spin at about
153 Hz in hover and up to 400 Hz,
so use RPM notch filtering (bidirectional DShot) as noted in the main report.

## Limits
Linear elastic, isotropic stand-in for a woven laminate (no ply-by-ply failure, no delamination), rigid clamp,
bolts not modelled as separate parts. Real crash loads are dynamic; the g values are the static load that
brings the arm to the design allowable.
